Shotstack Studio SDK

A powerful JavaScript library for creating and editing videos directly in the browser. Build sophisticated video editing capabilities into your web applications without requiring server-side processing.

Multi-track Editing

Create video compositions with multiple tracks and clips for advanced editing capabilities.

Media Support

Add images, videos, audio clips, text, and shapes to your compositions.

Real-time Preview

Preview edits in real-time with browser-based rendering for immediate feedback.

Browser Export

Export completed videos to MP4 format using browser-based FFmpeg processing.
